AppMoovies

Application Java de gestion de collection de films — ORM MyBatis + MySQL — Projet BTS SIO SLAM

À propos

AppMoovies est une application Java permettant de gérer une collection de films. Elle s'appuie sur une base de données MySQL et utilise MyBatis 3.5 comme framework de persistence pour simplifier les interactions SQL-objet via des fichiers de mapping XML.

Ce projet illustre la maîtrise de l'ORM MyBatis, du pattern DAO en Java et de la gestion de dépendances avec Maven dans un contexte de développement applicatif métier.

Fonctionnalités

  • Gestion CRUD d'une collection de films (création, lecture, modification, suppression)
  • Mapping SQL-objet via fichiers XML MyBatis (mapper/)
  • Accès à la base de données MySQL via le connecteur JDBC MyBatis
  • Couche service séparant la logique métier des accès aux données
  • Configuration de la connexion centralisée dans mybatis-config.xml
  • Pool de connexions JDBC géré automatiquement par MyBatis

Architecture

Le projet suit une architecture en couches avec séparation stricte des responsabilités :

  • Model — entités Java (Film, Genre…) représentant les tables MySQL
  • DAO — interfaces MyBatis dont les implémentations sont générées automatiquement à partir des fichiers XML de mapping
  • Mapper XML — fichiers *.xml contenant les requêtes SQL paramétrées et les résultats mappés
  • Service — logique métier orchestrant les appels DAO
  • Main — point d'entrée de l'application
