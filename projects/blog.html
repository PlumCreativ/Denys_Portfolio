Blog

Application web de gestion et publication d'articles — CRUD complet avec espace d'administration — Projet d'apprentissage BTS SIO SLAM

À propos

Blog est une application web développée en PHP permettant de créer, gérer et publier des articles en ligne. Ce projet a été conçu dans un objectif d'apprentissage et de mise en pratique du développement web back-end en PHP avec une base de données MySQL.

Il illustre la maîtrise des fondamentaux du développement web dynamique : gestion de sessions, requêtes paramétrées, séparation des responsabilités et interface d'administration sécurisée.

Fonctionnalités

  • Consultation de la liste des articles publiés
  • Création de nouveaux articles avec titre, contenu et métadonnées
  • Modification d'articles existants
  • Suppression d'articles avec confirmation
  • Espace d'administration sécurisé pour la gestion du contenu
  • Configuration centralisée de la base de données via config.php

Architecture

Le projet suit une architecture PHP procédurale avec séparation claire entre la configuration, les inclusions partagées (header, footer, navigation) et les pages fonctionnelles. La connexion à la base de données est centralisée et les requêtes sont paramétrées pour prévenir les injections SQL.

  • Point d'entrée unique index.php
  • Fichiers inclus réutilisables : includes/ (header, footer, nav)
  • Pages fonctionnelles séparées dans pages/
  • Styles découplés dans css/ et ressources dans assets/
  • Configuration BDD centralisée : config.php
