Media Stock

Application web mobile-first de gestion de matériel informatique et audiovisuel — Projet BTS SIO SLAM

À propos

MediaStock est une application web mobile-first de gestion de matériel informatique et audiovisuel. Elle permet la gestion d'un inventaire complet, le suivi des prêts et retours, ainsi que l'identification unique de chaque matériel via un QR code scannable depuis smartphone.

L'application est entièrement conteneurisée avec Docker, garantissant un environnement reproductible et portable. Développée en BTS SIO SLAM, session 2025, par Yanis ADIDI — période de réalisation : octobre–novembre 2025.

Fonctionnalités

  • CRUD complet de l'inventaire : ajout, modification, archivage du matériel
  • Génération automatique et impression d'un QR code unique par matériel
  • Enregistrement des prêts par scan QR depuis smartphone (caméra intégrée)
  • Suivi des retours et clôture automatique des prêts
  • Blocage des prêts si le matériel est déjà emprunté
  • Filtrage et recherche dynamique par catégorie, disponibilité et état
  • Gestion des utilisateurs : rôles étudiant / intervenant
  • Authentification administrateur avec expiration de session (5 minutes)
  • Archivage logique (pas de suppression physique)

Architecture technique

Architecture MVC léger implémentée en PHP procédural avec Docker Compose. Le frontend communique avec le backend via des appels fetch() vers une API REST PHP. Le dossier public/ est le DocumentRoot Apache, protégeant le code métier.

  • Frontend → fetch() → API PHP (Apache) → PDO → MySQL (Docker volume)
  • 3 services Docker : web (PHP 8.2), mysql (8.0), phpMyAdmin
  • Modélisation base de données selon la méthode Merise
  • Connexion PDO centralisée avec variables d'environnement
